# Adaptive Card System

## Overview

The adaptive card system provides randomized skeleton UI layouts for small data returns in the conversational interface. When users ask for specific types of data (appointments, lists, schedules, etc.), the system automatically displays appropriate skeleton card layouts.

## Architecture

### Components

1. **AdaptiveCards.tsx** - Library of 10 skeleton card layouts
2. **AdaptiveCardRenderer.tsx** - Renders selected card layouts with animations
3. **adaptiveCardSelector.ts** - Smart selection logic based on query type

### Card Layouts

| Layout Type | Use Case | Example Queries |
|------------|----------|----------------|
| `list-item` | Task lists, checklists | "show my medications", "list tasks" |
| `three-column` | Image grids, dashboards | "show patients", "display stats" |
| `two-column` | Side-by-side content | "compare data", "show summary" |
| `media` | Rich content with images | "patient profile", "show record" |
| `stats` | Metrics, numbers, KPIs | "dashboard", "statistics", "metrics" |
| `timeline` | Activity feeds, history | "recent activity", "history" |
| `calendar` | Schedules, appointments | "calendar", "appointments", "schedule" |
| `profile` | User/patient info | "profile", "patient details" |
| `table` | Data rows, records | "data table", "records", "results" |
| `form` | Input forms | "create", "new", "form" |

## Design Tokens

Cards use skeleton styling with two key colors:
- **Border**: `border-border` - Outline elements (boxes, checkboxes)
- **Fill**: `bg-primary-light` - Filled elements (text placeholders, blocks)

This creates a subtle, minimalist skeleton appearance that matches the overall design system.

## Query Categorization

The system automatically categorizes queries into:
- **list** - Shows list-item, timeline, or table cards
- **schedule** - Shows calendar, timeline, or list-item cards  
- **stats** - Shows stats, three-column, or two-column cards
- **people** - Shows profile, timeline, or media cards
- **data** - Shows table, two-column, or stats cards
- **form** - Shows form or two-column cards
- **general** - Shows list-item, two-column, or media cards

## Randomization

Each query triggers:
1. **Category Detection** - Keywords determine the query type
2. **Layout Selection** - Random selection from category-appropriate layouts
3. **Count Determination** - 1 card or 2-4 cards based on query (list vs. single item)
4. **Staggered Animation** - Cards animate in with 0.1s delay between each

## Usage in Messages

When the assistant responds to a small data request:

```typescript
{
  role: 'assistant',
  content: "I've gathered everything neatly for you.",
  adaptiveCards: ['list-item', 'list-item', 'timeline']
}
```

The `adaptiveCards` array is automatically generated by `getMockResponse()` based on the user's query.

## Adding New Card Layouts

1. Create component in `AdaptiveCards.tsx`:
```tsx
export function MyNewCard({ className = '' }: CardProps) {
  return (
    <div className={`border border-border bg-background rounded-lg p-4 ${className}`}>
      {/* Your skeleton layout */}
    </div>
  );
}
```

2. Add to `cardComponents` mapping in `AdaptiveCardRenderer.tsx`

3. Add to `categoryLayouts` in `adaptiveCardSelector.ts`

4. Update type definition in `adaptiveCardSelector.ts`

## Design Philosophy

- **Minimal & Clean** - Subtle borders, generous whitespace
- **Skeleton-first** - Show structure immediately, no loading spinners
- **Context-aware** - Different layouts for different query types
- **Randomized** - Variety prevents UI fatigue
- **Token-driven** - All styling from design tokens
- **Enterprise aesthetic** - Professional, understated appearance
